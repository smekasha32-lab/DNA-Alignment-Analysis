# DNA Alignment Analysis

# Overview
DNA Alignment Analysis is a Python-based bioinformatics tool that compares two DNA sequences and evaluates their similarity.

# Featuresgi
- Aligns and compares two DNA sequences
- Counts the number of matches and mismatches between sequences
- Calculates similarity percentage between sequences
- Reports mismatch positions
- Calculates alignment scores of the two sequences using customizable scoring system
- Handles sequences of different lengths safely 

# Technologies
- Python

# Output
- Counts of matches and mismatches
- Alignment score
- Similarity percentage
- Mismatch positions and nucleotide differences
